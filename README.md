# 微信研究资料整理器

这是一个本地运行的质性研究资料采集、分类与编码原型，适合整理已取得书面同意的公众号文章和朋友圈材料。

## macOS 独立应用

GitHub Actions 会分别生成：

- `微信研究资料整理器-macOS-Intel.zip`
- `微信研究资料整理器-macOS-AppleSilicon.zip`

解压后把 `.app` 拖入“应用程序”。因为默认构建不使用 Apple 开发者证书，第一次运行请按住 Control 点击应用（或右键），选择“打开”，再确认一次。以后可正常双击。独立应用不要求电脑安装 Python，并使用 macOS 自带的离线 Vision OCR 识别中英文截图。

应用数据保存在 `~/Library/Application Support/微信研究资料整理器/`，更新或移动应用不会覆盖数据库。

若需要自行触发构建：把整个项目上传到 GitHub 仓库，在 Actions 页面选择 “Build macOS apps”，点击 “Run workflow”。完成后在该次运行的 Artifacts 区域下载两个 ZIP。

## 它能做什么

- 根据你主动提交的公众号文章链接提取标题、正文和发布日期；
- 导入朋友圈截图、HTML、TXT、Markdown，或直接粘贴文字；
- 按受访者代号管理知情同意，不保存真实姓名；
- 根据 `categories.json` 自动打初步标签，并支持人工标签、备忘与复核状态；
- 全文检索，导出 Excel 编码表、Word 个案档案和 SQLite 数据库备份；
- 受访者撤回同意时，一键删除该代号的所有记录和已上传图片。

## 安装与启动

需要 Python 3.10–3.12。在项目目录运行：

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows：.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

然后打开 <http://127.0.0.1:8765>。所有数据默认保存在本机 `data/` 文件夹。

Windows 也可以在安装 Python 后双击 `start_windows.bat`；macOS 可在终端中运行 `bash start_mac.command`。第一次启动会自动建立独立环境并安装依赖。

源码运行模式如需识别中文截图，可安装 Tesseract 及 `chi_sim` 中文语言包；打包后的 macOS 独立应用不需要 Tesseract。

## 推荐工作流

1. 在“知情同意”页面登记受访者代号、同意书编号/位置、日期和范围。
2. 公众号：逐条粘贴研究相关的文章链接。若微信返回访问验证，将页面另存为 HTML 后上传，或复制正文。
3. 朋友圈：在微信中对相关内容截图，或复制文字后导入。建议在来源说明里写日期、可见范围和原始文件编号。
4. 在“检索与编码”中核对正文、自动标签和 OCR，补充人工编码与研究备忘。
5. 完成人工复核后导出。论文引用前回到原始资料核验语境和措辞。

## 伦理与安全边界

- 工具不登录微信、不读取客户端数据库、不绕过验证码，也不批量枚举他人账号。
- “能看到”不自动等于“可用于研究”。书面同意应具体覆盖朋友圈/公众号内容、保存期限、引用方式、撤回机制和是否允许保存图片。
- 朋友圈可能包含未同意参与研究的第三人信息；导入前应裁掉头像、昵称、位置、评论者姓名等非必要信息。
- `data/` 中可能有敏感资料。建议使用系统磁盘加密，将项目放在学校批准的加密设备中，不同步到公开网盘或 Git 仓库。
- 自动标签只是检索辅助，不能替代研究者编码。OCR、发布日期和文章正文都必须人工复核。

## 自定义分类

直接编辑 `categories.json`：键是主题名，值是触发词列表。重启程序后，新导入资料会使用新的分类表。已有资料不会自动重算，以免覆盖研究过程记录。

## 当前限制

- 微信会不定期改变页面结构或触发访问验证，因此链接采集不是百分之百成功；失败时使用 HTML/文本导入。
- 原型不下载公众号图片、音频、视频和评论，也不会抓取朋友圈时间线。
- PDF 暂未自动提取；可先复制文字，或逐页转为图片再导入。
- 本地界面没有用户登录功能，只监听 `127.0.0.1`；不要改成 `0.0.0.0` 暴露到网络。
